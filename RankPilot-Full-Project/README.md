# RankPilot — AI-Powered SEO Intelligence & Product Suite

## Quick Start (Zero-Install Browser Mode)
Double-click `RankPilot-Standalone.html` to open the full interactive application immediately in Chrome, Safari, Edge, or Brave.

## Local Development (Node.js / Vite / React)
1. Unzip `RankPilot-Full-Project.zip`
2. Run in terminal:
   ```bash
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.
